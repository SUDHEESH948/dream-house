## Platform
web

## Stack

## Product Purpose
Recreate https://yarchitect-seven.vercel.app/ with maximum visual and interactive fidelity, using Dream House branding. The user subsequently requested replacing all reference photographs with independently sourced photography.

## Brand Commitments
Dream House is the requested name. Preserve reference composition, section order, typography, colors and behavior. All shipping photographs must be independently sourced; do not use Y Architects images. No alternative visual direction is needed.

## Capabilities and Constraints
Responsive desktop, tablet and mobile layouts. Smooth scrolling, image reveals, parallax, a cinematic hero and horizontal selected works. Honor reduced motion. Content and photography from the reference are demonstration content pending real studio information.

## Evidence on Hand
The public HTML, compiled styles and client code of the reference were inspected. Native browser inspection was blocked by the browser tool's URL verification; visual fidelity has not yet been verified in a browser. Reference code confirms a three-image, six-second hero slideshow with two-second crossfades and separate mobile images.
